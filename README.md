# AI-Database-App

# 🤖 AI-Powered TODO Assistant (CLI)

自然言語（普段の言葉）で話しかけるだけで、AIが意図を汲み取りデータベースにタスクを自動登録・管理してくれるCLIベースのタスク管理アプリです。

![デモ動画](ここにターミナルで動かしているGIF動画のリンクを貼ります。例: demo.gif)

## 🎯 開発の背景と目的
既存のTODOアプリは「入力フォームを開いて、タイトルを打ち込み、カレンダーから日付を選ぶ」という手間がかかりました。そこで、「明日の15時までに企画書を出すのメモして」と**チャット感覚で話しかけるだけで完結するシステム**を構築できないかと考え、開発しました。

バックエンドにおけるデータベース（SQLite）の基礎的なCRUD処理と、Gemini APIのFunction Callingを連携させたアーキテクチャの学習・実証を目的としています。

## ✨ 主な機能
- **自然言語によるタスク登録:** AIが文章から「タスク名」と「期限」を自動抽出してDBに保存。
- **コンテキストを理解した検索と更新:** 「今のタスク教えて」「さっきの牛乳のタスク完了にして」といった文脈を理解し、AIが適切なSQL関数を呼び出します。
- **論理削除によるステータス管理:** タスク完了時は物理削除（DELETE）せず、ステータスフラグ（0/1）の更新（UPDATE）による履歴保持（論理削除）を採用しています。

## 🏗 システム構成図 (Architecture)

ユーザーの自然言語入力をGemini APIが解析し、実行すべき関数と引数（JSON）をPythonに返却。PythonがSQLiteを操作する橋渡し（仲介）を行う設計です。

```text
[ ユーザー ] 
   │ (自然言語)
   ▼
[ Gemini API (Function Calling) ] 
   │ (関数実行の指示と抽出したデータ)
   ▼
[ Python (仲介・DB操作) ]
   │ (SQL: INSERT, SELECT, UPDATE)
   ▼
[ SQLite (データベース) ]
